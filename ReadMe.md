## 剔除深度异常点(depth < 0.5 or depth very big)
  1. 一般而言，正确深度被观测到的次数会很多

  2. 对于 `depth<0.5` 的点，其特点是单次量测即可得到很小的不确定度，但由于其是错误的，

     它被观测到的次数 **少，<2**.

  3. 量测深度的方差过大，一般发生在 `depth>5.0` 时，因为方差大的点我们没办法使用它，应该舍弃该量测，如

    `d: [3.81 5.4 8.84], uncertainty:[ 3.43 1.6]`

  4. 量测深度的方差过小，一般发生在 `depth<0.5` 时，这很明显不符合单目测量精度，应该舍弃该量测，如

    `d: [0.521 0.498 0.448], uncertainty:[ 0.0502 0.0236]`

  5. 即便如ORBSLAM是有特征匹配的，其生成地图点时，也要求地图点被至少3 KeyFrame观测，中间还有n Frame可以观测，
     
     因此，观测次数是一个三角化效果评估的重要依据
<br>
<br>
  
## LSD识别异常值的做法：
  1. 统计观测次数、量测失败时增大方差、设置量测深度的先验最大、最小方差

  2. LSD-SLAM通过光度残差及深度测量不确定度来设置weigth，同时设置胡伯核以减小异常值影响，
     在连续的位姿估计过程中，使得landmark和pose逐渐收敛
